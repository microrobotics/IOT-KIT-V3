#### Getting Started with IoT 

<small>
The **Getting Started with IoT Kit** is structured into two practical modules, taking you from hardware assembly to programming real-world devices.</small>

### 1. ESP32 IoT Controller Assembly and Testing

Assemble the ESP32 IoT Controller, verify its operation, and become familiar with its features and hardware.

### 2. Interfacing and Programming Sensors and Actuators

Learn how to connect, program, and control a wide range of sensors and actuators using the ESP32 platform.
